# 运营工具工作台

这是运营工具工作台的公开下载与自动更新仓库，用于向已授权用户发布 Windows 安装包。

## 使用说明

- 软件可公开下载，但业务功能需要管理员提供的授权码。
- 授权码首次使用后只绑定一台电脑；同一码不能在第二台电脑激活，同一电脑也不能占用第二个授权码。
- 授权成功后，本机只保存由 Windows 当前账户加密的设备密钥和服务端签名租约；不保存明文授权码。
- 授权首次绑定、刷新、解绑和停用由独立授权服务处理；GitHub 仓库不保存授权码哈希、明文授权码或签名私钥。
- 未授权时仍可检查和安装软件更新。

## 仓库边界

本仓库是二进制发布仓库，不是源码开源仓库。公开内容仅包括安装包、差分更新文件、更新清单和版本说明。不上传源码、Cookie、店铺登录数据、业务报表、授权数据库、服务端密钥或明文授权码。
