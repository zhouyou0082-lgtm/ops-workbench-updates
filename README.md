# 运营工具工作台

这是运营工具工作台的公开下载与自动更新仓库，用于向已授权用户发布 Windows 安装包。

## 使用说明

- 软件可公开下载，但业务功能需要管理员提供的授权码。
- 授权成功后，本机只保存由 Windows 当前账户加密的授权回执；不保存明文授权码。
- 仓库中的 `activation-manifest.json` 只包含授权码的 SHA-256 哈希、状态和 Ed25519 签名，不包含明文授权码或签名私钥。
- 未授权时仍可检查和安装软件更新。

## 仓库边界

本仓库是二进制发布仓库，不是源码开源仓库。公开内容仅包括安装包、差分更新文件、更新清单、版本说明和签名授权清单。不上传源码、Cookie、店铺登录数据、业务报表、授权私钥或明文授权码。
