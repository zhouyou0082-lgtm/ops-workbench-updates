单屏助手 2.5.9

远程协助现在可以直接使用：
1. 官方 RustDesk 1.5.1 Windows x86_64 便携客户端已内置，双方安装本版助手后无需再下载、安装或手动选文件。
2. 点“打开 RustDesk”或“连接朋友”时在后台离线准备组件，准备期间防止重复启动。失败后恢复按钮并显示原因。
3. 内置组件随助手安装、便携包和线上更新一起提供，每次启动前核对官方哈希；缓存损坏时从安装包内修复，无需联网。
4. 组件原样分发，提供完整 AGPLv3 许可、固定版本源码与 hbb_common 子模块。可在远程协助页查看许可或获取对应源码。
5. 可切换使用自己的客户端，或一键恢复使用内置客户端。

远程画面仍为独立窗口，密码验证、共享与操作权限、断开连接在 RustDesk 中处理。打开助手不会自动启动远程组件；退出助手不会自动断开已有远程会话。
助手不保存远程密码，朋友 ID 只临时输入。保留原界面、电影版光效与音效，以及原有配置和统计。

内置客户端为 Windows x86_64 版本。尚未完成两台电脑的异地画面与操作实测，连通和质量取决于双方网络和远程连接服务。更新下载沿用官方备用线路，目前没有国内托管服务器。
