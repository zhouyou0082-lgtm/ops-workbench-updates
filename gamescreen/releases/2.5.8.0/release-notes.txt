单屏助手 2.5.8

新增远程协助入口：
1. 左侧“远程协助”可打开本机 RustDesk，共享 ID 给朋友；也可输入朋友 ID 打开独立连接窗口。
2. 自动检测常见安装目录，支持自行选择官方下载的便携版客户端，提供官方下载与说明入口。
3. 密码、共享权限、键鼠授权与断开连接在 RustDesk 窗口处理。启动客户端不代表连接成功，退出助手不会自动结束独立远程会话。
4. 朋友 ID 仅临时输入，离开页面或隐藏窗口时清空，不写入助手配置；助手不收集、保存或传递远程密码。
5. 本机客户端路径不会随配置导出，也不会被其他电脑的导入设置覆盖；不自动连接、不安装远程服务、不修改防火墙。
6. 小窗口左侧导航可滚动，避免新增入口与底部状态重叠。

保留原主界面、游戏准备、报告导出、声音偏好撤销、电影版光效与音效。

首次使用需要双方自行下载或安装 RustDesk（本包未包含该客户端）。跨网络连通和权限以 RustDesk 为准，两台电脑的异地实测尚未完成。
更新仍使用原有独立签名和 GitHub 官方备用下载线路，没有国内下载服务器，不能保证所有地区无代理可用。
