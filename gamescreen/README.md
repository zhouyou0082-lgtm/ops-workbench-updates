# 单屏助手

当前版本：2.5.15.0。

K20 灯光支持开机延迟检测、休眠唤醒与 USB 变化后重连。临时失败时重新打开接口并有限重试；后台只查询，不重置USB、不更改灯光或声音，保留未保存的灯光编辑和游戏恢复记录。声音页可点“重新连接”。

能出声但实体灯光按键也失灵时，可能是音箱灯光控制部分初始化、固件或供电/连接异常；自动重连不保证修复设备卡死或系统USB识别失败。本版不自动刷固件、重启USB或修改全局节能。
新增独立声音模式：在「声音」页读取当前声音或新建模式，设置系统输出、总音量/静音及各软件的输出通道、音量/静音，保存后从托盘「切换模式」一键切换。最多16个模式，不联动亮度、屏幕遮罩或灯光。未播放的软件会在音频会话出现后应用一次，后续手动音量保留。缺失设备明确提示，固定/独占输出的游戏可能需要在游戏内选择系统默认，或重启音频。

默认使用白色界面，设置→外观可选「月白 / 夜幕」，与主题色独立保存，记住后续手动选择。主窗口、托盘及菜单同步适配，副屏黑幕与开场效果保持原色。
新增 MCHOSE K20 USB 灯光控制：开关、7 档设备灯效、亮度、周期、双灯区与 RGB，保存自定义方案；支持游戏开始切换、结束恢复，后续手动选择优先。入口在「声音 → 音箱灯光」，无需另外安装 M HUB。此灯光适配仅支持 K20 USB 连接。

更新建连改在后台，连接时显示等待动画、秒数和当前线路；连续有进度的慢速下载不再被原来的 5 分钟总时限中断。仍校验发布签名和程序完整性。旧版更新卡住时，请先右键托盘退出旧助手，解压本版便携包，运行 GameScreen.exe，并在设置点击「安装到这台电脑」，沿用原配置和统计。

修复多屏连续调整亮度时旧请求覆盖新值的问题，以及托盘旧读值覆盖新操作的问题；主窗口与托盘同步硬件确认结果。DDC/CI首次读取失败和慢回读进行有限重试，多物理屏逐一确认。

默认启动后检查、每2小时后台检查，发现新版自动显示“立即更新 / 稍后”提示。游戏期间暂缓提示与安装，桌面空闲1分钟后再提醒。选择稍后后同版本24小时内不重复；失败15分钟后重试。可在设置关闭自动检查。旧版首次请在「设置 → 线上更新」手动检查并升级，之后按新版策略提示。

游戏结束默认安静恢复，不弹收官窗口或替代通知，统计照常记录。旧配置首次升级会关闭结束提示，之后可手动开启。启动仪式保留当前样式，采用真正透明的四边羽化，减轻入场与收尾的缩放，修复文字闪现和中途关闭跳变。保留当前光效、欢迎名称、音效和原界面，可在概览点击“预览开场”查看。

「远程协助」已内置官方 RustDesk 1.5.1 Windows x86_64 便携客户端。双方安装本版助手后即可直接使用，无需另行下载。首次点击共享本机或连接朋友时，助手会在后台离线准备并校验组件。组件随程序安装和线上更新；缓存损坏时从内置副本修复。远程协助统一使用内置 RustDesk，去掉自选与切换客户端的额外入口。

远程画面在独立窗口显示。密码、共享与操作权限、连接结果和断开在 RustDesk 中处理。助手不保存远程密码，朋友 ID 临时输入、离开页面或隐藏窗口时清空。退出助手不会自动结束独立远程会话。跨网络连接依赖双方网络与远程服务，尚未完成两台电脑的异地实测。

RustDesk 客户端原样分发，许可为 GNU AGPLv3。软件内「组件与许可」可离线查看完整许可，准备后的文件位于当前用户的 AppData\Local\GameScreen\remote\RustDesk\1.5.1。

软件输出偏好撤销只恢复软件偏好，不保证固定或独占输出的音频实时迁移。外接屏亮度控制需要 DDC/CI 及连接设备支持。没有内置自动补帧，视频工具为独立入口。

本目录使用独立签名清单与固定版本路径，历史版本保留，与仓库内其他软件的 Release 和更新文件分开。分发包不包含维护者配置、统计、日志或私钥。

配置和统计保存在当前 Windows 用户目录。更新在游戏运行或恢复未完成时暂缓安装，启动自检失败时尝试回退。

更新使用 GitHub 官方 API、原始文件与网页下载入口，不内置账号令牌或第三方代理。尚未部署国内下载服务器，不保证所有地区无代理可用。
