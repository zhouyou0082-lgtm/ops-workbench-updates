# 单屏助手

Windows 游戏前准备与副屏助手。当前版本：2.4.2。

## 下载与使用

[下载便携包](https://raw.githubusercontent.com/zhouyou0082-lgtm/ops-workbench-updates/main/gamescreen/releases/2.4.2.0/GameScreen-2.4.2-portable.zip) · [备用网页下载](https://github.com/zhouyou0082-lgtm/ops-workbench-updates/raw/main/gamescreen/releases/2.4.2.0/GameScreen-2.4.2-portable.zip)

解压后运行 GameScreen.exe，可选择安装到当前电脑。首次也可以由朋友直接发送本便携包，无需从 GitHub 下载。之后在程序内检查更新，会自动选择官方备用线路下载。

在“设置 → 线上更新”检查新版并点击“下载并更新”。默认空闲时每天检查一次，可关闭。游戏运行时暂缓安装，更新保留配置与统计。早期没有更新入口的版本需要先手动安装一次带更新功能的新版本。

检查更新和下载均支持官方备用线路切换，每条线路都需要通过同一发布签名、文件大小、SHA256、软件标识及版本验证。当前线路均属于 GitHub，不同地区和运营商的直连情况可能不同；目前未部署国内服务器。高级更新来源支持维护者另行部署的国内 HTTPS 更新源。

本软件使用独立的 [签名更新清单](https://raw.githubusercontent.com/zhouyou0082-lgtm/ops-workbench-updates/main/gamescreen/latest.json)，与本仓库其他软件的更新入口分开。

本目录只发布程序、分发包、签名更新清单与版本说明，不包含源码、用户配置、游戏记录或发布私钥。
