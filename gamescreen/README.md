# 单屏助手

当前版本：2.5.5.0。

在软件中打开「设置 → 线上更新 → 检查更新 → 下载并更新」。也可以下载便携包，解压后运行 GameScreen.exe，在引导中选择安装到这台电脑。

- [便携包](releases/2.5.5.0/GameScreen-2.5.5-portable.zip)
- [独立程序](releases/2.5.5.0/GameScreen.exe)
- [本次更新说明](releases/2.5.5.0/release-notes.txt)

本版完善慢网下载：持续传输时更新停顿计时，显示速度、已收大小及当前来源；下载完成后继续核对签名、大小、哈希和程序身份。连接无响应、传输停顿和整次下载仍有超时限制，可取消和重试。

亮度读取合并为后台队列，显示器重连后丢弃旧读数；重新检测同时更新屏幕列表。外接屏硬件控制需要显示器开启 DDC/CI，并由连接设备正常透传；读取或写入未确认时如实提示。

保留原主界面、五款可选开场、欢迎名称、电影版离线音效、横竖屏遮罩、软件音频输出及游戏准备。开场可以独立预览，不启动游戏或执行配置调整。

配置与统计保存在当前 Windows 用户目录，分发包只含程序和使用说明，不含维护者配置、日志、源码、发布密钥或第三方补帧工具。

本目录使用独立签名清单和固定版本路径，与仓库中其他软件的 Release 和更新文件分开。历史版本保留，下载失败不会把未完成文件当成可安装程序。

更新通过 GitHub 官方 API、原始文件和网页下载入口重试，不内置账号令牌或第三方代理。尚未部署国内下载服务器，不能保证所有地区及运营商无代理可用。

光效来源和许可可在软件内查看：原四款基于 React Bits / Light Pillar，MIT + Commons Clause；电影版光效与声音由本项目制作，随软件离线提供。
