# 单屏助手

当前版本：2.5.11.0。

默认启动后检查、每2小时后台检查，发现新版自动显示“立即更新 / 稍后”提示。游戏期间暂缓提示与安装，桌面空闲1分钟后再提醒。选择稍后后同版本24小时内不重复；失败15分钟后重试。可在设置关闭自动检查。旧版首次请在「设置 → 线上更新」手动检查并升级，之后按新版策略提示。

- [便携包](releases/2.5.11.0/GameScreen-2.5.11-portable.zip)
- [独立程序](releases/2.5.11.0/GameScreen.exe)
- [更新说明](releases/2.5.11.0/release-notes.txt)

游戏结束默认安静恢复，不弹收官窗口或替代通知，统计照常记录。旧配置首次升级会关闭结束提示，之后可手动开启。启动仪式保留当前样式，采用真正透明的四边羽化，减轻入场与收尾的缩放，修复文字闪现和中途关闭跳变。保留当前光效、欢迎名称、音效和原界面，可在概览点击“预览开场”查看。

「远程协助」已内置官方 RustDesk 1.5.1 Windows x86_64 便携客户端。双方安装本版助手后即可直接使用，无需另行下载。首次点击共享本机或连接朋友时，助手会在后台离线准备并校验组件。组件随程序安装和线上更新；缓存损坏时从内置副本修复。也支持使用用户自选客户端。

远程画面在独立窗口显示。密码、共享与操作权限、连接结果和断开在 RustDesk 中处理。助手不保存远程密码，朋友 ID 临时输入、离开页面或隐藏窗口时清空。退出助手不会自动结束独立远程会话。跨网络连接依赖双方网络与远程服务，尚未完成两台电脑的异地实测。

RustDesk 客户端原样分发，许可为 GNU AGPLv3。软件内「组件与许可」可离线查看完整许可，准备后的文件位于当前用户的 AppData\Local\GameScreen\remote\RustDesk\1.5.1。

保留原主界面、五款开场、自定义名称、电影版离线音效、游戏准备计划预览、检查报告导出、声音输出偏好撤销、横竖屏遮罩、亮度兼容与慢网更新。

软件输出偏好撤销只恢复软件偏好，不保证固定或独占输出的音频实时迁移。外接屏亮度控制需要 DDC/CI 及连接设备支持。没有内置自动补帧，视频工具为独立入口。

本目录使用独立签名清单与固定版本路径，历史版本保留，与仓库内其他软件的 Release 和更新文件分开。分发包不包含维护者配置、统计、日志或私钥。

配置和统计保存在当前 Windows 用户目录。更新在游戏运行或恢复未完成时暂缓安装，启动自检失败时尝试回退。

更新使用 GitHub 官方 API、原始文件与网页下载入口，不内置账号令牌或第三方代理。尚未部署国内下载服务器，不保证所有地区无代理可用。

原四款光效基于 React Bits / Light Pillar，MIT + Commons Clause；电影版光效与声音为本项目制作，离线提供。完整许可见软件内“光效来源与许可”。
