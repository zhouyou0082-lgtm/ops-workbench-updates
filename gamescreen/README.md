# 单屏助手

Windows 游戏前准备与副屏助手。当前版本：2.4.3。

[下载便携包](https://raw.githubusercontent.com/zhouyou0082-lgtm/ops-workbench-updates/main/gamescreen/releases/2.4.3.0/GameScreen-2.4.3-portable.zip) · [备用网页下载](https://github.com/zhouyou0082-lgtm/ops-workbench-updates/raw/main/gamescreen/releases/2.4.3.0/GameScreen-2.4.3-portable.zip)

解压运行 GameScreen.exe，可安装到当前用户。已有 2.4.2 用户可在“设置 → 线上更新”下载并更新。首次也可以让朋友直接发送便携包。

## 本版改动

- 遮罩适配一横一竖、不同分辨率及缩放比例，音乐与硬件卡片按屏幕方向布局。
- 声音列表增长后自动调整托盘面板位置，长列表与整个面板均可滚动。
- 汇总所有可用播放设备上的软件，持续接收新音频会话。
- 右键软件，或点主界面软件行右侧的输出按钮，选择耳机、音箱或恢复“跟随系统默认”。显示当前实际输出，切换失败会提示；部分播放器需要暂停后继续播放。

更新默认空闲时每天检查一次，可关闭；游戏运行时暂缓安装，保留配置和统计。清单使用单屏助手固定发布密钥签名，程序核对大小、SHA256、标识及版本。官方备用线路失败自动切换，当前未部署国内服务器，各地直连情况可能不同。支持维护者另配国内 HTTPS 更新源。

只发布程序、便携包、签名清单和版本说明，不包含源码、用户配置、游戏记录或发布私钥。与本仓库其他软件的更新入口分开。
