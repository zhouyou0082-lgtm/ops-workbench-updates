Windows 游戏前准备与副屏助手。当前版本：2.4.4。

[下载便携包](https://raw.githubusercontent.com/zhouyou0082-lgtm/ops-workbench-updates/main/gamescreen/releases/2.4.4.0/GameScreen-2.4.4-portable.zip) · [备用网页下载](https://github.com/zhouyou0082-lgtm/ops-workbench-updates/raw/main/gamescreen/releases/2.4.4.0/GameScreen-2.4.4-portable.zip)

解压运行 GameScreen.exe，可安装到当前用户。已有 2.4.2/2.4.3 用户在“设置 → 线上更新”下载并更新，也可以由朋友直接发送便携包。

## 本版改动

- 修复横屏主屏限制竖屏副屏遮罩的实际高度、底部未盖满；同时修正原生窗口与内部画布的限制。
- 软件选择输出后检查活动音频实际位置；区分偏好保存、播放确认、未迁移、等待播放与设备断开。
- 软件行与右键菜单显示实际播放设备，勾选仅表示 Windows 输出偏好。系统默认卡片明确标为系统默认。
- 未迁移时可手动选“兼容切换：同时设为系统默认”，会影响其他跟随系统默认的软件。固定设备的游戏仍可能需要在游戏内重选输出或重新启动。本版尚未在朋友的永劫无间中实测，不承诺所有游戏运行中无缝切换。

307 项测试通过；屏幕外原生窗口验证了 1080×1920、1440×2560、2160×3840 竖屏及 3840×1080 超宽屏的窗口、客户区和内部画布尺寸。本机隔离静音进程验证了启动前分流成功和已有音频流未迁移时准确提示，测试后恢复自身偏好。混合缩放包含几何验证，朋友真实双屏布局仍需实机确认。

更新默认空闲时每天检查一次，可关闭；游戏运行时暂缓安装，保留配置和统计。清单使用单屏助手固定发布密钥签名，程序核对大小、SHA256、标识及版本。官方备用线路失败自动切换，当前未部署国内服务器，各地直连情况可能不同。支持维护者另配国内 HTTPS 更新源。

只发布程序、便携包、签名清单和版本说明，不包含源码、用户配置、游戏记录或发布私钥。与本仓库其他软件的更新入口分开。
