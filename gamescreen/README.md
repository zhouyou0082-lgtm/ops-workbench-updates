# 单屏助手

当前版本：2.5.8.0。

软件内打开「设置 → 线上更新 → 检查更新 → 下载并更新」，或解压便携包后运行程序，在引导中选择安装到这台电脑。

- [便携包](releases/2.5.8.0/GameScreen-2.5.8-portable.zip)
- [独立程序](releases/2.5.8.0/GameScreen.exe)
- [更新说明](releases/2.5.8.0/release-notes.txt)

新增「远程协助」页：打开 RustDesk 共享本机，或输入朋友 ID 打开独立远程连接窗口。支持检测已安装客户端、选择便携客户端和访问官方下载页。双方需先准备 [RustDesk 客户端](https://rustdesk.com/download)，本分发包没有捆绑远程引擎。

密码、共享与操作权限、连接结果和断开均在 RustDesk 中处理。助手不保存远程密码，朋友 ID 只用于本次输入，离开页面或隐藏窗口时清空。本机客户端路径不参与配置导出或被其他电脑导入覆盖。退出助手不会自动结束独立远程会话。跨网络连接依赖客户端与连接服务，尚未完成两台电脑的异地实测。

保留原主界面、五款开场、自定义名称、电影版离线音效、游戏准备计划预览、检查报告导出、声音输出偏好撤销、横竖屏遮罩、亮度兼容与慢网更新。小窗口左侧导航现在支持滚动。

声音菜单中的“撤销上次软件输出选择”仅恢复该软件的上一步偏好，不改变系统默认或其他软件。软件重启、原设备断开或偏好被手动修改时停止。固定或独占设备的游戏仍可能需要重选输出或重新打开音频；恢复偏好不代表实际音频已迁移。

外接屏亮度控制需要 DDC/CI 及连接设备支持；读取或写入未确认时如实提示。没有内置自动补帧，视频工具为独立入口。

本目录使用独立签名清单与固定版本路径，历史版本保留，与仓库内其他软件的 Release 和更新文件分开。分发包只含程序与使用说明，不包含维护者配置、统计、源码、日志或私钥。

配置和统计保存在当前 Windows 用户目录。更新在游戏运行或恢复未完成时暂缓安装，启动自检失败时尝试回退。

使用 GitHub 官方 API、原始文件与网页下载入口，不内置账号令牌或第三方代理。尚未部署国内下载服务器，不保证所有地区无代理可用。

原四款光效基于 React Bits / Light Pillar，MIT + Commons Clause；电影版光效与声音为本项目制作，离线提供。完整许可见软件内“光效来源与许可”。
